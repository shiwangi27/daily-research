a baby and an LLM

BabySim's baby learns to balance with REINFORCE. The same policy-gradient loop — the identical estimator — is how GPT, Claude, and DeepSeek are post-trained with RLHF and GRPO. What changes between them isn't the algorithm. It's the policy network: three weights here, a transformer there.

01The loop both live inside

Reinforcement learning is one feedback loop: a policy proposes an action from the current state, the environment answers with the next state and a reward, and after a batch of tries the policy is nudged toward whatever earned more reward. Everything else is a detail of what fills each box.

03The only real difference: the policy network

Swap the box labelled π_θ and everything else stays put. BabySim's policy is three numbers dotted with the state. An LLM's policy is a stack of transformer blocks — the repo already ships one (NanoLM: RoPE, RMSNorm, ReLU², QK-norm), the same shape as nanochat / nanoGPT. Both map state → a distribution over actions → a sample.

This is the swap that matters. Replacing BabySim's 3-weight policy with the repo's NanoLM transformer — and torques with tokens — turns the exact same training loop into nanochat-style RL post-training. Nothing about the gradient estimator changes.

04Even the training pipeline rhymes

BabySim's two model families map onto the two halves of an LLM's life. Imitating a fixed ideal pose is supervised learning; earning reward under real physics is RL.

05REINFORCE → PPO → GRPO: only the advantage changes

All three plug into the same gradient ∇J = 𝔼[∇log π · Â]. They differ in one place — how they compute the advantage Â, i.e. what they compare each trajectory against. That's the whole ladder.

What BabySim has

  • Gaussian policy, exact score-function gradient
  • Batch-mean, std-normalised baseline
  • Return-weighted credit (whole-episode)
  • Fixed exploration σ

What the ladder adds

  • PPO: a value critic + GAE (lower variance), clipped updates (stability)
  • GRPO: drop the critic, use the group mean; add a KL leash to a reference model
  • reward-to-go instead of one blunt return
  • a transformer policy for nonlinear control

Which is exactly the experiment plan: each upgrade is one clean knob — critic vs no critic, clip vs no clip, group baseline, MLP policy — measured on the same balance task by the same metric (steps kept upright). That's how we'll race REINFORCE, PPO and GRPO next.
